InsightLab 🔍

An interactive Python web app to explore, clean, visualize, and analyze datasets using machine learning.

🚀 "Live Demo" (https://k28qgnuqsigpqe7lzxvcqq.streamlit.app/)

✨ Features

- Explore and clean datasets
- Create interactive visualizations
- Train machine learning models
- Generate predictions

🛠️ Tech Stack

Python • Streamlit • Pandas • NumPy • Plotly • Scikit-learn

💻 Run Locally

pip install -r requirements.txt
python -m streamlit run app.py

👨‍💻 About

Built as a practical project while learning Python, Artificial Intelligence, and data science.
